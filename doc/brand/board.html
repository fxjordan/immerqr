Concept

Immergrün: green through every winter

An evergreen keeps its leaves when everything else drops them. Most "free" QR generators hand out codes that wilt: they route through the site's own redirect, and once the trial ends the code stops working or sits behind a paywall. An ImmerQR code holds your link itself, so there is nothing that can wilt.

Mark

A finder pattern with a leaf for an eye

Every QR code has three square "eyes" in its corners. The mark is one of them, with the solid centre grown into a leaf. It is the same shape the codes themselves use, so the logo and the product look like family.

Code style

"Blatt im Auge": how ImmerQR draws codes

Round modules, square outer rings, a leaf in each eye. Every rule below was checked by decoding test codes with OpenCV's two QR detectors, at full size and shrunk to 300 px.

✓ Default

Dots + square ring + leaf eye

Decoded in all test runs. This is what simple mode produces.

✓ Plain option

Classic squares, all ink

For people who want the most conservative code. Always one click away.

✕ Not allowed

Leaf-shaped outer ring

Looks best, but failed every decode test. Scanners locate a code by its square rings, so they stay square.

✕ Not allowed

Light green modules

Shoot green on white is 1.5 : 1. Modules stay fir or ink; colour lives in the eyes only.

Do

  • Say what the code contains, word for word.
  • "du" in German: friendly, not salesy.
  • Labels that say what happens: "PNG laden".
  • Garden metaphors in small doses: one per screen at most.

Don't

  • No "Pro", "Premium" or upgrade hints, ever.
  • No exclamation marks or growth-hacking copy.
  • No eco claims: the green is about lasting, not about CO₂.
